⚠️ Antes de começar

Você precisa de duas coisas prontas:
  1. Um repositório vazio já criado na sua conta do GitHub (pode estar vazio, sem README).
  2. Um Personal Access Token com permissão de escrita. Para gerar: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → marque o escopo repo.
O token só é usado no seu navegador, direto para a API do GitHub — esta página não tem backend próprio e não armazena nada.
