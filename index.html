Enviar projeto completo para o GitHub

Esta página já tem os 86 arquivos do projeto embutidos (client/, server/, tests/, package.json). Preencha os dados abaixo e toque em enviar -- cada arquivo vai ser criado direto no repositório, na pasta correta, via API do GitHub.

Antes de usar: crie um repositório VAZIO no GitHub (sem README) e gere um Personal Access Token (Settings > Developer settings > Personal access tokens > Tokens (classic) > Generate new token, com a permissão repo marcada). O token funciona como uma senha: nao compartilhe com ninguem. Esta pagina só envia dados para api.github.com, para nenhum outro lugar.
